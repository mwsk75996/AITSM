# Dokumentation

Denne mappe indeholder projektdokumentation, kravspecifikationer og tekniske referencer for AITSM Engineering ApS’ IoT-projekt.

## Struktur

- `assets/` – AITSM Engineering ApS-logoer
- `references/requirements/` – projektets kravspecifikationer
- `references/standards/` – relevante standarder
- `references/hardware/` – hardware- og produktdokumentation
- `extracted/` – tekstudtræk, PDF-metadata og genererede preview-billeder fra referencerne
